# BigBasket Category Performance Diagnostic

This repository contains the complete data pipeline and diagnostic analysis for BigBasket's category performance, utilising SQLite, Google Sheets/Excel, Python/Pandas, and Tableau Public.

## Project Deliverables

* **[Data Story & Tableau Dashboard](DATA_STORY.md)**: Contains the live Tableau Public URL and strategic business recommendations.
* **[AI Prompting Log](ai_log.md)**: Contains the RCTCF-structured prompts and verification steps.
* **[SQL Scripts](.)**: Contains `01_foundations.sql`, `02_aggregation_joins.sql`, and `03_reporting.sql`.
* **[Python Cleaning & Analysis](analysis.ipynb)**: Contains the Jupyter Notebook for raw data deduplication, IQR outlier capping, and cross-validation.
* **[Spreadsheet Cross-Check](bigbasket_category_crosscheck.xlsx)**: Contains the pivot and XLOOKUP reconciliations.
